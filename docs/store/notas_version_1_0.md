# Notas de la versión 1.0 · prueba cerrada (es-ES)

Para Play Console > Prueba cerrada > Notas de la versión, idioma `es-ES`. Límite: 500 caracteres.

Recuento a mano: 59 + 145 + 75 + 66 + 52 + 54 caracteres por línea, más 5 saltos de línea = **456/500**.

```
<es-ES>
Primera versión de prueba de Paddock. Gracias por probarla.
- Ocho juegos de grupo: Carrera de caballos, El Infiltrado, Trivia, Geografía, Abecedario, ¿Quién es más probable?, ¿Qué preferirías? y Yo nunca.
- Copa de la noche: marcador común, podio final y resultado para compartir.
- Tres niveles de contenido: Suave, Picante y Atrevido (solo +18).
- Funciona sin internet, sin cuentas y sin anuncios.
¿Algo falla o no se entiende? Avísame: me ayuda mucho.
</es-ES>
```

Notas:
- Las etiquetas `<es-ES>` las pone Play Console si se pega en el editor por idiomas; no cuentan para el límite.
- No menciona el modo opcional para mayores de edad (igual que las capturas).
- Para producción, quitar "de prueba" y la última línea (ver `docs/store/ficha_es.md`).
